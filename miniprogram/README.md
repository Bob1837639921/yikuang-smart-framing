# 一框微信小程序体验版

这是与网页原型并列的原生微信小程序工程。

## 体验方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件所在的 `miniprogram` 文件夹。
4. AppID 保持“测试号 / 游客模式”，点击导入即可。

首页可直接选择测试作品，也可以通过“拍照 / 选图试装”调用相册或相机。核心流程包括四点边缘校正、去褶效果对比和画框选择。

## 本地框料管理体验

进入“框料库”后可以先看到一条“胡桃木金色欧式雕花（测试）”示例；也可以点击“管理员入口”，输入体验 UUID `oneframe-admin-demo` 新增框料。新增框料时需要手动填写参数，并分别上传：

- 正面纹理图（必传）
- 截面/侧面图（必传）
- 45°拼角图（可选）
- 雕花细节图（可选）

尺子只是拍摄时的比例参照，系统不会自动识别尺寸；管理员需要填写框宽、框深、内沿和倒角。点击“生成 3D 并发布”后，本地原型会保存 `geometry`、`surface` 和 `model3d` 配置，并按参数指纹复用缓存。正式服务接入后，再把本地模拟的 `modelUrl` 替换成服务器生成的 GLB 地址。
