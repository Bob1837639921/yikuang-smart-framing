# 一框微信小程序体验版

这是与网页原型并列的原生微信小程序工程。

## 体验方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件所在的 `miniprogram` 文件夹。
4. AppID 保持“测试号 / 游客模式”，点击导入即可。

首页可直接选择测试作品，也可以通过“拍照 / 选图试装”调用相册或相机。核心流程包括四点边缘校正、去褶效果对比和画框选择。

## 本地框料管理体验

进入“框料库”后可以看到内置样品；也可以点击“管理员入口”，输入体验 UUID `oneframe-admin-demo` 新增框料。新增框料需要上传三类原始素材：

- 正面纹理图（必传）
- 侧面纹理图（必传）
- 截面轮廓图（必传，白底、截面朝上、镜头垂直）

管理员还需手动填写框料名称、元/米价格、材质类型、型面类型、框宽、框深、侧面显示宽度、内沿和倒角。尺子只是拍摄时的读数参照，系统不会自动识别尺寸；截面图负责型面，不负责表面颜色。45° 拼角由几何生成，也不需要上传拼角图。

官网材料后台使用相同字段，并从三类输入生成两套渠道产物：官网使用四向纹理、微观高度图、截面曲线和 PBR 参数；微信端读取压缩后的正面/侧面纹理、简化轮廓点、尺寸和价格，以原生 Canvas 渲染轻量预览。当前原型可以导出同一材料记录的渠道包，正式服务接入后由材料 API 和对象存储替代浏览器与微信本地缓存。
