# Homepage font

Noto Serif SC variable, weights 400–900, licensed under the adjacent OFL.txt.
Source: Google Fonts CSS2 API, family `Noto Serif SC:wght@400..900`.
The active studio subset contains unique characters from the homepage, studio
sections, header, footer, brand and canonical material copy. Regenerate with
`python scripts/prepare-home-font.py` when their copy changes.
The active font is `home-serif-studio.woff2` (166,352 bytes), locally served
with font-display: optional. The earlier subset is retained for the saved version.
The SVG hero handwriting does not depend on this font.
