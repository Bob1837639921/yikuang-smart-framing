# Homepage font

Noto Serif SC variable, weights 400–900, licensed under the adjacent OFL.txt.
Source: Google Fonts CSS2 API, family `Noto Serif SC:wght@400..900`.
The `text` subset contains unique characters from HomePage.tsx, SiteHeader.tsx,
SiteFooter.tsx and BrandMark.tsx. Regenerate when their copy changes.
The font is served locally as WOFF2 (156,580 bytes) with font-display: optional.
The SVG hero handwriting does not depend on this font.
