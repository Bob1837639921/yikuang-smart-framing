# 一框官网

这是仓库内唯一的 React 官网入口。根目录的 Vite 配置将开发服务器和生产构建指向本目录，避免官网代码与微信小程序页面、素材和配置混在一起。旧的网页端小程序手机模拟器已经移除，官网不会再维护一套与原生小程序重复的页面流程。

## 分层约定

- `src/App.tsx`：官网运行时入口。
- `src/site/`：官网页面和可复用站点组件，目前包含首页、导航和页脚。
- `public/`：仅供官网构建使用的静态图片和品牌素材。

小程序业务和素材请修改 `../miniprogram/`，不要从官网目录反向引用小程序相对路径。需要共用的业务数据或 API 客户端，后续放到根目录的 `packages/`，由两端显式依赖。
