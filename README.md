# 一框智能装裱

一框智能装裱（YiKuang Smart Framing）是一款面向裱画店的微信小程序产品原型。顾客可以拍摄或上传字画、照片、儿童画等作品，校正作品边缘，预览去皱整理效果，选择画框和卡纸，并保存方案或向门店询价。

> 当前仓库是用于验证产品流程、视觉和动效的移动端交互原型，不是可直接提交微信审核的原生小程序工程。正式版本需要将现有交互迁移到微信小程序运行时，并接入相机、Canvas、图像处理服务和门店后台。

## 已实现功能

- 黄白动漫风移动端界面
- 无底部 Tab 的画框主题导航
- 拍照取景器与相册上传入口
- 四点拖动式作品边缘校正
- 旋转照片、重新识别和透视处理过程
- 国画、儿童画、摄影、抽象画等测试案例
- 皱宣纸作品测试案例
- 基于同一张原图的确定性视觉去皱处理
- 原貌、轻度去皱和模拟托裱效果对比
- 原木、黑铝、奶油白和亮黄框料切换
- 卡纸开关、颜色和留边宽度调整
- 作品尺寸、参考价格、方案保存和门店询价流程
- iPhone 与 Pixel 移动设备预览

## 核心体验流程

```text
拍照或选择照片
        ↓
自动识别作品边缘
        ↓
手动调整四个校正点
        ↓
透视拉正与背景裁剪
        ↓
作品状态检测与视觉去皱
        ↓
选择画框、卡纸和尺寸
        ↓
保存方案并提交门店询价
```

## 去皱处理说明

仓库中的 `scripts/dewrinkle_art.py` 使用确定性的图像处理方法，不调用生成式图片模型，也不会重新创作作品。

处理逻辑包括：

1. 识别并裁取纸张区域。
2. 从原图亮度估计褶皱造成的低频光照场。
3. 降低空白纸张区域的褶皱明暗对比。
4. 对深色墨迹区域降低处理强度，尽量保护笔触。
5. 输出轻度与强力两档视觉整理结果。

单张照片只能减弱视觉上的褶皱阴影，不能恢复纸张真实的三维形状。强力处理也可能损失淡墨，因此产品默认推荐轻度去皱，并始终保留原图用于对比和门店判断。

运行示例：

```powershell
python scripts/dewrinkle_art.py `
  public/assets/test-wrinkled.png `
  public/assets/test-dewrinkled-light.png `
  --strength 0.62
```

## 本地运行

环境要求：

- Node.js 20+
- pnpm 10+
- Python 3.10+（仅重新生成去皱测试图时需要）
- Python 包：`Pillow`、`numpy`

安装并启动：

```bash
pnpm install
pnpm dev
```

默认访问地址：

```text
http://localhost:5173/
```

生产构建：

```bash
pnpm build
```

代码与移动运行时检查：

```bash
pnpm check:runtime
```

## 转为正式微信小程序

正式版本建议拆分为以下模块：

### 小程序端

- 使用 `camera` 组件或 `wx.chooseMedia` 获取照片。
- 使用 Canvas 2D进行画框、卡纸、阴影和作品合成。
- 使用小程序页面栈实现拍摄、校正、整理、试装和询价流程。
- 配置相机、相册和用户图片相关隐私声明。

### 图像处理服务

- 自动检测作品四边。
- 使用透视变换将斜拍作品拉正。
- 分析褶皱、反光、模糊和破损程度。
- 对原图执行非生成式视觉去皱。
- 生成高清装裱效果图。

### 商家后台

- 作品案例管理。
- 框料、卡纸、玻璃、价格和库存管理。
- 门店计价规则配置。
- 顾客方案、询价和订单管理。

## 推荐开发顺序

1. 将拍照、相册和四点校正迁移到微信小程序。
2. 接入透视校正和视觉去皱服务。
3. 使用真实框料纹理完成 Canvas 合成。
4. 建立框料、案例和计价后台。
5. 接入用户方案、客服和门店询价。
6. 最后再评估墙面预览、AR和智能搭配推荐。

## 当前限制

- 相机页面目前为浏览器原型模拟。
- 四点校正已经可交互，但原型中未执行真实透视矩阵变换。
- 画框效果用于流程验证，尚未使用门店真实框条纹理和45度拼角素材。
- 询价数据未连接数据库或真实门店系统。
- 去皱只处理视觉阴影，不能替代实体托裱和修复。
